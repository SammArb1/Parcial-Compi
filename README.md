# The Feline Graph Chronicles

Proyecto final del curso de Lenguajes y Compiladores. Consiste en un sistema de rescate basado en teoría de grafos para ayudar a Pola y Minerva a salvar a Nina de las garras de Limón.

**Integrantes del equipo:**
* Samuel Arbeláez
* Nicolás Aguas

**Estructura del Proyecto:**
* `src/main/.../core/`: Algoritmos puros (BFS, DFS, Dijkstra, Floyd-Warshall, Bellman-Ford, Kruskal). Cero dependencias gráficas.
* `src/main/.../gui/`: Interfaz gráfica (Swing/JavaFX) que interactúa con el usuario.
* `src/test/.../core/`: Pruebas unitarias para validar matemáticamente cada misión.
